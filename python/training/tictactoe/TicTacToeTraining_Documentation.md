# Tic-Tac-Toe Training Documentation

Documentation for the Reinforcement Learning agent trained to play Tic-Tac-Toe.

## Environment

*   **Game**: Tic-Tac-Toe.
*   **State**: Grid state.
*   **Actions**: Place X/O in cell 0-8.
*   **Reward Function**:
    *   +10 for Win.
    *   -10 for Loss.
    *   0 for Draw.
    *   -1 for Invalid Move.
