# MASTERCHIP8

A high-performance, cross-platform CHIP-8 emulator with a C++ core, Qt GUI, and Python bindings for AI training.

## Features

*   **Core**: C++
*   **Display**: 64x32 resolution with configurable colors and grid.
*   **Input**: Full keyboard mapping.
*   **Sound**: Simple buzzer.
*   **AI Ready**: Python bindings for Reinforcement Learning.
*   **Cross-Platform**: Runs on Windows, Linux, and macOS.
